# Odtwarzacz

Czysta strona do oglądania zestawu filmów: dedykacja, duże okno odtwarzacza i plakaty do wyboru.

Adres:

https://gladiator2201.github.io/odtwarzacz/

Zestaw filmów jest zapisany w końcówce adresu (po znaku #). Osoba, która otworzy łącze, widzi tylko odtwarzacz i plakaty.

Kod do osadzenia w Google Sites leży w pliku `KOD_EMBED.txt`.
